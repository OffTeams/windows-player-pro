# Windows Player Pro

Мультимедийный плеер для Windows 10 и 11 со встроенным загрузчиком.

Версия 1.0 (Open Beta). Автор: OFFTeams.

- **Воспроизведение** на libmpv + FFmpeg: HEVC/AV1/VVC 10-bit, HDR10, HDR10+, Dolby Vision, TrueHD Atmos, DTS-HD, FLAC 24-bit, MKV, M2TS, HLS, DASH и всё остальное, что знает FFmpeg. Аппаратное декодирование D3D11VA / NVDEC / QSV.
- **Онлайн-просмотр без подвисаний**: прямые потоки идут через локальный прокси, который забирает их короткими частями по 8 МБ (сайты вроде YouTube режут скорость одного длинного запроса). Окно подстраивается под пропорции видео.
- **Загрузка через yt-dlp**: окно настройки с раздельным выбором видео и звука, языком дорожки, контейнером, форматом аудио и субтитрами; пакетная загрузка; пауза и продолжение.
- **Сериалы на сайтах с плеером Collaps**: сезоны и серии, озвучки по названиям, субтитры, качество до 1080p; можно скачать серию, сезон или все серии.
- **Сайты, которые yt-dlp не знает**: разбор HTML, затем страница открывается во встроенном Chromium и сетевые запросы к медиа перехватываются. Видео под DRM помечается как недоступное.
- **Резервная папка**: если основная недоступна, файл сразу сохраняется в резервную, с уведомлением.
- **Фоновый помощник** (`WPPHelper.exe`): распознаёт ссылки в буфере обмена, даже когда плеер закрыт, показывает превью найденного и при необходимости запускает плеер. Автозапуск — в настройках, установщике или Диспетчере задач («Автозагрузка»).
- **Эквалайзер** на 10 полос, светлая и тёмная темы в стиле «Параметров» Windows 11, иконка в стиле Windows 11 / 10 / 7.

## Установка

Скачайте `WindowsPlayerPro-<версия>-setup.exe` из Releases и запустите. Права администратора не нужны: программа ставится в `%LOCALAPPDATA%\Programs\Windows Player Pro`, файлы сжимаются прозрачным сжатием NTFS. Обновления приходят сами: плеер показывает уведомление, скачивает и ставит новую версию, история, плейлист и загрузки сохраняются.

## Разработка

```bash
powershell -ExecutionPolicy Bypass -File setup.ps1
```

Создаёт `.venv`, ставит зависимости и скачивает в `vendor\` libmpv, FFmpeg, Deno и MinGit с официальных страниц релизов. Запуск из исходников: `run.bat` или ярлык на рабочем столе. Из рабочей копии плеер обновляется через git.

Сборка exe и установщика (нужен Inno Setup 7, `ISCC.exe` в `build\tools\inno` или в PATH):

```bash
powershell -ExecutionPolicy Bypass -File build.ps1
```

Проверка:

```bash
.venv\Scripts\python.exe tools\selftest.py build\selftest
```

## Данные

Настройки, история, плейлист, загрузки и журналы: `%APPDATA%\WindowsPlayerPro`.
